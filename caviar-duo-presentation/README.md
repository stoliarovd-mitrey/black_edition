# Презентация «Новое поколение Caviar»

Онлайн-редактор: https://stoliarovd-mitrey.github.io/black_edition/caviar-duo-presentation/

Семь страниц исходного PDF сохранены без изменений. Перед контактами добавлен восьмой слайд о предоплате 50% при предзаказе кастомного iPhone Duo от Caviar. Размер страницы: 1080 × 1620.

## Редактирование и выгрузка

1. Откройте редактор и выберите слайд слева.
2. Меняйте текст в правой панели. Можно менять размер и цвет текста. Перетаскивайте элементы мышью, а маркерами рамки меняйте её ширину и высоту. В панели есть точные координаты X/Y и размеры. Стрелки сдвигают выбранный элемент на 1 пиксель, Shift + стрелки на 10 пикселей. Кнопка «Отменить» возвращает предыдущее состояние. Правки автоматически сохраняются в браузере.
3. «Скачать PDF» выгружает все 8 слайдов. Неизменённые страницы копируются из PDF без пересборки, сохраняются активные ссылки. Страницы с правками получают обновлённый текст и JPEG-изображение. Экспорт автоматически подбирает качество и разрешение, чтобы итоговый PDF не превышал 3 МБ (3 000 000 байт).
4. «Скачать HTML» сохраняет автономный редактор с текущими правками, шрифтом, изображениями и исходным PDF. Он работает без интернета.
5. «Сохранить правки» скачивает `presentation.json`. Загрузите его вместо одноимённого файла в этой папке GitHub и нажмите Commit changes, чтобы обновить общую версию на GitHub Pages. Также можно править текст непосредственно в JSON через GitHub.

Правки из браузера не передаются автоматически в GitHub. Для переноса на другой компьютер используйте JSON или автономный HTML. Локальные правки имеют приоритет, пока общая версия не изменится. При обновлении JSON в GitHub редактор загрузит обновлённую общую версию.

## Как сохранена точность

Исходный PDF содержит слайды как плоские растровые изображения, без отдельного текста и информации о шрифте. Редактор использует извлечённые из PDF оригинальные изображения и накладывает новый текст только на изменённые поля. При отсутствии правок экспортирует исходные страницы PDF. Новый слайд использует фирменный Nunito Sans из приложенной базы знаний. Для редактируемых полей используются Nunito Sans и исходные координаты, с автоматической подгонкой длинного текста.

Основные файлы: `presentation.json` (тексты и координаты), `editor.js` (редактор и PDF), `editor.css` (интерфейс), `assets/` (слайды, маски текста, шрифт и PDF), `vendor/` (локальная библиотека pdf-lib). Внешние API и секреты не требуются. PDF доступен также по адресу `assets/presentation.pdf`.

Nunito Sans: SIL Open Font License, см. assets/OFL.txt. pdf-lib: MIT, см. vendor/PDF-LIB-LICENSE.md.

## Перемещение и размер элементов

Позиции и размеры рамок сохраняются в `rect: [x, y, width, height]` каждого текстового поля. PDF, автономный HTML и файл правок используют эти координаты. Рамка и размер шрифта настраиваются отдельно: при сужении рамки текст автоматически переносится или уменьшается. Кнопка «Сбросить положение и рамку» возвращает исходную геометрию, сохраняя текст.

В меню элементов можно выбрать «Изображение слайда» и перемещать или масштабировать общую растровую композицию. Исходный PDF содержит фон, смартфоны и графические части кнопок в одной картинке. Поэтому этот слой изменяется целиком; отдельные смартфоны в нём не выделены. Текстовые поля остаются самостоятельными. При изменении изображения текст заново отрисовывается фирменным шрифтом.

Неизменённые слайды сначала экспортируются из исходного PDF. Если это мешает уложиться в 3 МБ, редактор сжимает изображения всех страниц. На изменённых слайдах активная ссылка следует за соответствующим текстовым элементом. Старые файлы правок по-прежнему поддерживаются.

## Ограничение размера PDF

Кнопка «Скачать PDF» проверяет размер готового файла. Первые попытки сохраняют неизменённые страницы из исходника и кодируют только изменённые страницы в JPEG. Если общий размер всё ещё больше 3 000 000 байт, редактор пересобирает все страницы с JPEG и поэтапно уменьшает качество и разрешение изображений. Сжатие останавливается при первом подходящем результате. Геометрия страниц 1080 × 1620, позиции элементов и активные ссылки сохраняются. Пунктирные рамки и маркеры не попадают в PDF. Финальная проверка предотвращает скачивание файла больше лимита. После выгрузки редактор показывает фактический размер в МБ. Эта функция также входит в автономный HTML.
