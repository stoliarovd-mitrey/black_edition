Элементы слайда

Перетаскивайте элемент мышью. Потяните за маркеры рамки, чтобы изменить размер. Стрелки двигают выбранный элемент, Shift увеличивает шаг.

Как сохранить результат

Правки автоматически сохраняются в этом браузере. «Скачать PDF» выгружает текущую версию размером не более 3 МБ, «Скачать HTML» создаёт автономный редактор.

«Сохранить правки» скачивает presentation.json. Замените им одноимённый файл в GitHub, чтобы обновить версию для всех.
