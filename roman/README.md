# Caviar · Роман Дворянинов

- `index.html` — публичная презентация, 4 слайда 600 × 900.
- `edit.html` — редактор: текст, изображения, позиции, размеры, цвета, ссылки, слои, дублирование, отмена и возврат.
- `published.json` — версия для всех посетителей; `original.json` — исходная версия.
- Исходный синий заменён на #111111, фон body страницы https://caviar-phones.ru/info/contacts/. Золотые акценты сохранены.

Редактор автоматически сохраняет черновик локально. «Опубликовать» записывает текущую версию в `roman/published.json` в ветке main через GitHub Contents API. Нужен fine-grained token для репозитория `stoliarovd-mitrey/black_edition` с доступом Contents: Read and write. Токен не сохраняется. GitHub Pages должен публиковать main / root (существующая конфигурация репозитория).

Публичная страница читает только опубликованную версию, независимо от локальных черновиков. При отсутствии сети доступна начальная презентация, встроенная в index.html.

«HTML для сайта» экспортирует один самостоятельный HTML с текущими правками, фотографиями и шрифтами внутри. Можно размещать как отдельную страницу или подключать iframe. Для интеграции в CMS без iframe перенесите main и стили в отдельный контейнер с изоляцией стилей. Прямая публикация в CMS caviar-phones.ru требует отдельно подключённого доступа к CMS и не выполняется редактором GitHub.

«Скачать проект» сохраняет JSON для резервной копии и переноса между компьютерами. «Открыть проект» загружает такую копию. Для восстановления исходника откройте original.json через «Открыть проект».

Изображения PNG/JPEG/WebP при загрузке уменьшаются до 1600 px и сохраняются в WebP. Менять QR без одновременного обновления его содержимого и ссылки следует только при смене контактов.

Проверка: синтаксис JS и структура/ссылки проекта. Визуальная проверка браузером в текущей среде недоступна.
