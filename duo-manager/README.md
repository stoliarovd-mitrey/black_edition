# iPhone Duo Caviar

Семь вертикальных слайдов, 1080 × 1620. Откройте index.html через статический сервер или GitHub Pages.

Редактор: тексты, размер и цвет шрифта, перемещение и изменение размера рамок, замена изображения, добавление и удаление текстов, добавление/дублирование/удаление и перестановка слайдов. Правки сохраняются в браузере. JSON позволяет переносить правки; замените presentation.json для обновления общей версии. HTML экспортирует автономный редактор со всеми изображениями. PDF содержит ссылки и автоматически сжимается (целевой размер 3 МБ, для больших пользовательских презентаций может быть выше).

Исходный PDF был растровым. Текст пересобран редактируемыми блоками, изображения исходных слайдов извлечены из PDF. Фон и типографика воспроизведены близко к оригиналу, но не являются побитовой копией. Новые изображения предоставлены пользователем.

## Открыть редактор

https://stoliarovd-mitrey.github.io/black_edition/duo-manager/

Для сохранения общей версии загрузите скачанный presentation.json в эту папку. Локальные правки в браузере не изменяют общую версию автоматически.
