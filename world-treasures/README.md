# Caviar World Treasures

Web presentation (6 slides) based on the supplied Caviar PDF. Edition: **7 pieces per model** (28 designs total).

- `index.html`: public viewer, arrow navigation and Print to PDF.
- `edit.html`: editor with draggable/resizable elements, local draft and GitHub-publishing support. GitHub PAT required to save to the repository. The PAT stays in memory and is never stored or sent elsewhere.
- `deck.json`: all editable copy and coordinates.
- `assets/*.webp`: product renders from the source PDF.

Publishing: Requires GitHub Pages to be enabled for the repository, deployment from `main` root. Links use `/black_edition/world-treasures/`.
