Как работать с редактором
1. Выберите сценарий, этап или вкладку «Тексты страницы». Для изменений в заголовках воронки и карточках откройте блок «Воронка». Изменения автоматически остаются в локальном черновике текущего браузера.
2. Нажмите «Посмотреть страницу менеджера», чтобы увидеть публичную версию. До публикации она не изменится.
3. Нажмите «Опубликовать на GitHub» и укажите ограниченный токен. После подтверждения редактор обновит только файл данных, не затрагивая дизайн.
4. На случай ограничений GitHub API можно скачать data.json и заменить им одноимённый файл в репозитории через GitHub.

Внимание: этот URL технически публичный. Он не защищён паролем и не содержит секретов; публикация возможна только с GitHub-токеном, обладающим правом записи. Не передавайте менеджерам токен доступа.
