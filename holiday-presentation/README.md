# Персональная праздничная подборка Caviar

Семь вертикальных слайдов 1080 × 1620 по ТЗ: https://docs.google.com/document/d/18hS0oi3yzsgYRJuU98sp8gAKucyTY2KXMNmw6T6CJo4/edit

Просмотр: https://stoliarovd-mitrey.github.io/black_edition/holiday-presentation/
Редактор: https://stoliarovd-mitrey.github.io/black_edition/holiday-presentation/?edit=1

В редакторе измените подпись на обложке и загрузите три изображения телефонов. Тексты остальных слайдов фиксированы. Правки сохраняются только в браузере менеджера; публичный шаблон не меняется.

«Скачать PDF» создаёт клиентскую версию с активными ссылками в контактах. «Скачать для клиента» создаёт автономный HTML со всеми фотографиями и шрифтом; панель редактора в нём отсутствует. JSON-подборка позволяет переносить редактируемое состояние между браузерами.

Исходные телефоны: Versus, Signature, Prestige из папки Google Drive, указанной в ТЗ. Подарочная фотография создана по референсу из ТЗ. Логотип, Nunito Sans и pdf-lib взяты из существующих материалов этого репозитория. Все ресурсы включены в index.html, внешние запросы не нужны.
