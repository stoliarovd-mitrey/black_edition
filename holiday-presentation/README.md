# Персональная праздничная подборка Caviar

Просмотр: https://stoliarovd-mitrey.github.io/black_edition/holiday-presentation/
Редактор: https://stoliarovd-mitrey.github.io/black_edition/holiday-presentation/?edit=1

Шесть основных вертикальных слайдов 1080 × 1620 и опциональный слайд контактов по ТЗ: https://docs.google.com/document/d/18hS0oi3yzsgYRJuU98sp8gAKucyTY2KXMNmw6T6CJo4/edit

В редакторе доступны подпись на обложке, три фотографии и выбор блока контактов: Данила Китов, Роман Дворянинов или без контактов. Имена менеджеров используются только в панели редактора; на слайдах и в клиентском HTML их нет. Контакты Романа: +7 930 064 28 03, @CAVIAR_SUPPORT, caviar-phones.ru.

Изображение можно выбрать кнопкой или перетащить в соответствующее поле. Перед открытием системного окна нет обработки фотографий. Фильтр файлов использует расширения PNG/JPG/JPEG/WebP. После выбора сжатие выполняется через асинхронный canvas.toBlob; обновляется только нужная миниатюра. Полная подборка сохраняется асинхронно в IndexedDB. Маленькие настройки сохраняются отдельно; прежние подборки из localStorage поддерживаются.

«Скачать PDF» создаёт 6 или 7 страниц в зависимости от контактов, с активными ссылками. «Скачать для клиента» создаёт автономный HTML, включая выбранные фотографии и вариант контактов. Панель редактора удаляется. JSON позволяет перенести редактируемую подборку в другой браузер. Публичный шаблон от правок в браузере не меняется.

Исходные телефоны: Versus, Signature, Prestige из папки Google Drive в ТЗ. Подарочная фотография создана по референсу из ТЗ. Логотип, Nunito Sans и pdf-lib взяты из существующих материалов репозитория. Все ресурсы включены в index.html.
