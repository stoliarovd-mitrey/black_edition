# Персональная праздничная подборка Caviar

Просмотр: https://stoliarovd-mitrey.github.io/black_edition/holiday-presentation/
Редактор: https://stoliarovd-mitrey.github.io/black_edition/holiday-presentation/?edit=1

Вертикальные слайды 1080 × 1620 с изменяемым количеством вариантов телефона и опциональным слайдом контактов по ТЗ: https://docs.google.com/document/d/18hS0oi3yzsgYRJuU98sp8gAKucyTY2KXMNmw6T6CJo4/edit

В редакторе доступны подпись на обложке, варианты телефонов и выбор блока контактов: Данила Китов, Роман Дворянинов или без контактов. Имена менеджеров используются только в панели редактора; на слайдах и в клиентском HTML их нет. Контакты Романа: +7 930 064 28 03, @CAVIAR_SUPPORT, caviar-phones.ru.

Изображение можно выбрать кнопкой или перетащить в соответствующее поле. Перед открытием системного окна нет обработки фотографий. Фильтр файлов использует расширения PNG/JPG/JPEG/WebP. После выбора сжатие выполняется через асинхронный canvas.toBlob; обновляется только нужная миниатюра. Полная подборка сохраняется асинхронно в IndexedDB. Маленькие настройки сохраняются отдельно; прежние подборки из localStorage поддерживаются.

«Скачать PDF» создаёт страницы по текущему составу подборки, с активными ссылками. «Скачать для клиента» создаёт автономный HTML, включая выбранные фотографии и вариант контактов. Панель редактора удаляется. JSON позволяет перенести редактируемую подборку в другой браузер. Публичный шаблон от правок в браузере не меняется.

Исходные телефоны: Versus, Signature, Prestige из папки Google Drive в ТЗ. Подарочная фотография создана по референсу из ТЗ. Логотип, Nunito Sans и pdf-lib взяты из существующих материалов репозитория. Все ресурсы включены в index.html.


## Вставка телефона и удаление фона

В редакторе выберите «Дизайн 01», «Дизайн 02» или «Дизайн 03». На странице каталога Caviar нажмите правой кнопкой по изображению, выберите «Копировать изображение» и в редакторе нажмите Ctrl+V (⌘V на Mac). Также доступны кнопка «Вставить из буфера», выбор файла и перетаскивание. Ссылка на страницу товара не заменяет скопированное изображение.

Фон удаляется автоматически в отдельном браузерном Worker. BiRefNet-lite 512 загружается по первому запросу и кэшируется браузером; нужен интернет для первой загрузки. WebGPU используется при наличии подходящего адаптера, иначе WASM. Телефоны не отправляются на сервер обработки. Прозрачные PNG/WebP сохраняют исходную прозрачность. После обработки пустые поля обрезаются, готовый телефон вписывается в слайд. Можно вернуть фон или отменить последнюю замену. Пока идёт обработка, экспорт заблокирован, чтобы в PDF и HTML не попало прежнее фото.

Подготовленный фон слайда «Персонализация» создан в Higgsfield моделью Nano Banana 2.1. Он встроен в HTML, как и остальные изображения.

Внешние зависимости удаления фона загружаются только при редактировании: Transformers.js 4.2.0 (Apache-2.0), ONNX Runtime (MIT), BiRefNet-lite 512 (MIT). Источники и лицензии: https://github.com/huggingface/transformers.js, https://github.com/microsoft/onnxruntime, https://github.com/ZhengPeng7/BiRefNet, https://huggingface.co/studioludens/birefnet-lite-512. Клиентский HTML и PDF включают уже обработанные изображения и не требуют загрузки моделей.


## Дополнительные варианты телефона

Кнопка «+ Добавить вариант телефона» под списком изображений создаёт пустой слайд перед персонализацией и переводит редактор на него. Доступны Ctrl+V, вставка из буфера, загрузка файла и автоматическое удаление фона.

У каждого варианта есть кнопка «Удалить слайд». В подборке остаётся хотя бы один вариант телефона. Последний удалённый слайд можно восстановить кнопкой «Вернуть удалённый слайд» до перезагрузки редактора.

Миниатюры, нумерация, положение персонализации и контактов, PDF и клиентский HTML учитывают фактическое количество вариантов. Пустой вариант нужно заполнить или удалить перед экспортом для клиента. Черновики с пустыми вариантами можно сохранять в JSON. Изменяемое количество слайдов сохраняется в браузере; прежние JSON-подборки с тремя телефонами поддерживаются.
