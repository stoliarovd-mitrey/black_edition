Редактирование

Изменения сразу появляются на слайде. Для переноса строки используйте Enter.

Загруженные файлы автоматически подготавливаются в WebP и отправляются в GitHub только при публикации.

Публикация на GitHub

Изменения будут записаны в world-treasures-sales/index.html. Новые изображения загрузятся в папку assets. До публикации оригинальная страница не изменяется.

Нужен персональный токен GitHub с доступом Contents: Read and write к репозиторию stoliarovd-mitrey/black_edition. Токен не сохраняется в браузере.
