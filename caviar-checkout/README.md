# Caviar Checkout — адаптивный прототип

Самостоятельная HTML-страница оформления заказа на основе сохранённой корзины Caviar.

## Просмотр
Откройте `index.html` в браузере или используйте GitHub Pages, если он включён для репозитория.

## Дизайн
- **Nunito Sans** — фирменный шрифт согласно [базе знаний Caviar](https://teatromisterio.github.io/caviar-knowledge-base/#font).
- Фон: `#f8f7f4`, текст: `#201f1d`, акцент: `#981d2e`, дополнительный тёплый металлик: `#a48962`.
- Mobile-first адаптация до 320 px, на больших экранах форма слева и sticky-корзина справа.
- Без синих UI-элементов.

## Интерактивность
- Выбор iPhone 18 Pro / 18 Pro Max, объёма памяти и количества.
- Пересчёт по опубликованным вариантам цены модели «Рак».
- Удаление и восстановление товара, выбор оплаты, проверка обязательных полей.

**ВАЖНО:** это исключительно дизайн-прототип. Никаких POST, сетевой передачи данных или оплаты нет. Кнопка оформления показывает объясняющее окно и ссылку на реальную корзину сайта Caviar.

В сохранённом HTML отсутствуют сами файлы изображений — только локальные ссылки на них. Поэтому в прототипе использована **условная CSS-иллюстрация**, отмеченная как таковая, и ссылка на [фотографии реального товара](https://caviar-phones.ru/best-sellers/cancer_id28735/). Перед боевым внедрением нужно заменить иллюстрацию официальным изображением из CMS и подключить серверный checkout, CRM, аналитику и юридически выверенные формы согласия.

Существующие страницы репозитория не менялись.
