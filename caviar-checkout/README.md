- [Caviar Russia](https://caviar-phones.ru/) — палитра в духе основного сайта: чёрный, белый, бордовый. Синий фон референса полностью убран.
- Фирменный шрифт **Nunito Sans** из базы знаний.
- [Товар «Рак»](https://caviar-phones.ru/best-sellers/cancer_id28735/) — названия опций, лимитированность и рублёвые цены, пересчитываемые в браузере.

## Устройство страницы
01 — проверка заказа и конфигурации модели с динамической ценой.
02 — поля контактов и доставки.
03 — выбор способа оплаты, отдельный бордовый блок.
04 — комментарий к заказу.
05 — подтверждение с итоговой стоимостью.

Боковая навигация на десктопе, горизонтальные чипы на мобильном. Поддерживаются выбор модификации, памяти, количества, удаление и восстановление, проверка обязательных полей, модальное окно с сообщением о статусе прототипа.

## Важно
Это **только дизайн-прототип**: без передачи контактных данных, создания заказов, оплаты или интеграции с сайтом. Иллюстрация смартфона является условной и подписана; на официальные фотографии модели ведёт отдельная ссылка. Фотография подарочной упаковки взята из предоставленной базы знаний бренда.

Для запуска на действующем сайте нужно связать элементы с реальной корзиной и CRM, заменить иллюстрацию товара на фото из каталога, проверить правовые согласия и проверить продуктовые сценарии на мобильных устройствах.
