GITHUB PAGES

Опубликовать изменения

Тексты и медиа будут сохранены в stoliarovd-mitrey / black_edition. GitHub обновит посадочную после завершения сборки.

Нужен отдельный личный токен. Подключение GitHub в ChatGPT сюда не переносится. Токен остаётся только в открытом окне и не записывается в черновик или файлы.

Как создать токен

Откройте Fine-grained personal access token. Укажите Resource owner: stoliarovd-mitrey, выберите Only select repositories → black_edition и разрешение Repository permissions → Contents: Read and write. Скопируйте токен сюда целиком. Проверка доступа не публикует изменения страницы.
