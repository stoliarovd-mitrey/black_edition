Опубликовать изменения

Тексты и медиа будут сохранены в stoliarovd-mitrey / black_edition. GitHub обновит посадочную после завершения сборки.

Токен используется только для этой публикации и не сохраняется в черновике или файлах сайта.

Как создать токен

Откройте Fine-grained personal access token. Выберите только репозиторий black_edition и разрешение Contents: Read and write. Скопируйте токен сюда.
