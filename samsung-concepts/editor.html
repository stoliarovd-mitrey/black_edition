Опубликовать правки

Изменения будут сохранены в stoliarovd-mitrey/black_edition, ветка main. После этого GitHub Pages обновит сайт.

Токен используется только для обращения к api.github.com. Он не сохраняется в браузере, резервных копиях или репозитории.

Как создать токен

В GitHub создайте Fine-grained personal access token: Resource owner — stoliarovd-mitrey, Repository access — Only select repositories → black_edition. В Repository permissions установите Contents → Read and write. Остальные права не нужны.

Создать токен в GitHub ↗

Версия в GitHub отличается от исходной версии черновика. Можно загрузить её или явно заменить своим черновиком.

Резервная копия и экспорт

Черновик автоматически сохраняется в этом браузере. Резервная копия позволяет перенести его на другой компьютер.
