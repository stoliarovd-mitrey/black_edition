Сохранение и публикация

Черновик автоматически сохраняется только в этом браузере. Скачайте резервную копию, чтобы перенести его на другой компьютер.

Обновить страницу на GitHub

1. Скачайте файл page-content.js.
2. Откройте папку сайта и загрузите этот файл с заменой существующего.
3. Нажмите Commit changes. GitHub Pages обновит страницу.
