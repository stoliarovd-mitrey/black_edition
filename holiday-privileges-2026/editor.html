Изменения попадут в ветку main репозитория black_edition. После обновления GitHub Pages их увидят посетители лендинга.

Нужен fine-grained token для этого репозитория с правом Contents: Read and write. Редактор использует токен для публикации через GitHub и удаляет его после запроса.
